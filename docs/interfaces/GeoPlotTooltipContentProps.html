    OptionalsparklineValueOf

    sparklineValueOf?: (datum: GeoDatum<P>) => number

    The value of an event to draw in its sensor's sparkline (e.g. datum => datum.payload.delay). With it, the tooltip shows sparklines of the sensors' readings over time, from the events the data source holds: for an event, its sensor's (with the event marked); for an aggregate, a one-sensor cell's, and, on their lines, each listed group's whose events are one sensor's (a larger one for the hovered group). The larger sparklines (the event's sensor's, the one-sensor cell's, and the hovered group's) have axes: the readings' values, and the time (seconds) before the latest reading. Only one sensor's events are ever drawn together, so a sparkline never mixes sensors (or the quantities they measure). Without it, there are no sparklines.
