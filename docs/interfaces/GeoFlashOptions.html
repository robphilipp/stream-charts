    Interface GeoFlashOptions<P>

    How a GeoPlot's new events flash as they arrive (see its flash): each new event's ring, in its marker's color, grows from it and fades -- e.g. to show where something just happened (a phone just located, a sensor just reporting). Flashes show in every mode, so a roll-up's aggregates flash as their events arrive, too. The plot redraws up to 60 times a second while any ring shows.

    OptionalmergeDistance

    mergeDistance?: number

    Flashes of the same color and length that start within one flash's length of each other, and this close (px) to each other on the screen, are drawn as one ring, wider the more flashes it stands for -- so that a place with many new events (e.g. a city, seen from afar) pulses steadily, one ring at a time, rather than flashing ring over ring. Defaults to 20; 0 never merges them.

    Optionalradius

    radius?: number

    The radius (px, at the view's center) a flash's ring grows to. A ring is a circle on the earth, like the markers, so the projection shapes it as it shapes them (e.g. flattened toward a globe's edge). Defaults to 20.
