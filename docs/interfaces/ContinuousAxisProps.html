    OptionalautoScale

    autoScale?: boolean

    When true, the axis' domain grows to fit the data plotted against it: when the data on screen goes above (or below) the domain, the domain grows to include it (plus the autoScalePadding), but never past autoScaleMax (or autoScaleMin). The axis starts out at the domain prop, clamped to those limits. The domain only ever grows -- it's restored to its start when the plot's data is replaced (e.g. on a reset), or when the domain prop or the limits change. When false (the default), the domain is exactly the domain prop.

    For y-axes only (an x-axis' domain follows time, and its zooming and panning), in the plots that support it (the scatter, bar, and outlier plots). Elsewhere, it's ignored, with a warning.

    OptionalautoScaledDomain

    autoScaledDomain?: [min: number, max: number]

    The auto-scaled domain to start from when auto-scaling starts (e.g. when the axis is created), instead of the domain prop -- for keeping the axis' growth across remounts (e.g. navigating away from the chart and back), along with onAutoScale. Clamped to the limits.

    OptionalautoScalePadding

    autoScalePadding?: number

    The fraction of the axis' length left beyond the data's extreme when the axis grows, so the extreme point isn't drawn right on the edge (in the scale's own space, e.g. logarithmically for a log scale). From 0 to 0.45 (a larger value is treated as 0.45); defaults to 0.05.
