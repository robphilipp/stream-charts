    Interface CanvasContext

    Everything a draw-function needs to paint onto the chart's canvas, plus the API for registering and scheduling redraws. This is what gets threaded through useChart() in place of the old mainG (root SVG <g> selection) and container (root <svg> element).

    register

    register: (id: string, draw: DrawFn, zIndex?: number) => void

    Registers a draw function to be invoked on every redraw. Registering under an id that's already in use replaces the previous draw function for that id (so components can safely re-register on every render without leaking duplicate draws).
