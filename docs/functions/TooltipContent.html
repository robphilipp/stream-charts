    • TooltipContent<D, M, C>(

      ): ReactElement<unknown, string | JSXElementConstructor<any>> | null

      The building block of every tooltip's content. Put a component built on it inside a Tooltip, and when the mouse moves over one of the plot's elements, it calls capture with what the plot knows about that element, and shows what children renders, in a box next to the mouse (styled like the enclosing <Tooltip>). It hides again when the mouse leaves the element.

      Under the hood, it registers the chart's tooltip-content provider (one per chart: registering replaces the previous one), and a mouse-leave handler, and renders its box as a React portal on the page's body, which useTooltipPlacement places next to the mouse once it's rendered (and so its size is known).

      Type Parameters

      • D

        The type of the series' datum

      • M

        The type of the plot's tooltip metadata

      • C

        The type of the tooltip's content

      Parameters

      • props: TooltipContentProps<D, M, C>

        The capture and render functions, and the style

      Returns ReactElement<unknown, string | JSXElementConstructor<any>> | null

      The tooltip's box (a portal), or null when nothing is hovered

      Example

      function MyScatterTooltip(): JSX.Element {
          return (
              <TooltipContent<Datum, ScatterTooltipMetadata, {seriesName: string, count: number}>
                  capture={(seriesName, _time, {series}) => ({seriesName, count: series.length})}
              >
                  {({seriesName, count}) => <div>{seriesName}: {count} points</div>}
              </TooltipContent>
          )
      }
