    Class GeoDataSource<P>

    A data source for geo charts (the GeoPlot): it holds a series of sensor events for each group of sensors, drops events once they're older than dropDataAfter, and keeps its roll-ups (aggregates of the events, by place) up to date as events arrive and are dropped

    aggregates

    • aggregates(rollupName: string, seriesFilter?: RegExp): GeoAggregate[]

      Parameters

      • rollupName: string

        The name of a roll-up

      • OptionalseriesFilter: RegExp

        The series whose events count (e.g. the chart's series filter); all of them when not given. The roll-up of only some of the series is rolled up from the events held when it's first asked for, and then kept up to date as events arrive and are dropped, until another filter, or none, is asked for (one is kept for each roll-up) -- so asking again with the same filter is as quick as asking for all the series.

      Returns GeoAggregate[]

      The roll-up's aggregates, one per cell (empty for an unknown roll-up). The same array is returned until the roll-up's cells change.

    Protectedingest

    • ingest(data: GeoChartData<P>): void

      Adds each series' new events to it (registering a series the first time it shows up), then drops, from every series, the events older than dropDataAfter relative to the latest event so far -- so a group of sensors that has gone quiet still ages out. Calls onUpdateData with each series' new events.

    start

    • start(): void

      Subscribes to the generator, handing it the current series, so that a restarted source resumes from the data accumulated so far. Each chunk of data the generator emits is ingested into the series, and then emitted through chartDataUpdatesObservable. When the generator fails or completes, the source stops. A no-op when the source is already running, or has been disposed.

      Returns void
