    Class BaseStreamingDataSource<CD, D, S>Abstract

    The lifecycle shared by every kind of data source. Subclasses only supply how a chunk of chart data is ingested into the series, and how to find the latest time in the series.

    start

    • start(): void

      Subscribes to the generator, handing it the current series, so that a restarted source resumes from the data accumulated so far. Each chunk of data the generator emits is ingested into the series, and then emitted through chartDataUpdatesObservable. When the generator fails or completes, the source stops. A no-op when the source is already running, or has been disposed.

      Returns void

      Implementation of StreamingDataSource.start
