    Class OrdinalDataSource

    A data source for ordinal charts (e.g. the bar plot). Besides the series, it keeps the lifetime stats (from the chart data) and the windowed stats (over the data currently held) for each series, so they keep accumulating while no plot is mounted.

    Protectedingest

    • ingest(data: OrdinalChartData): void

      Adds each series' new points to it, copies the chunk's lifetime stats, updates the series' windowed stats for the new points, and then drops the points that are older than dropDataAfter relative to the chart-wide current time (the time of the latest datum over all series), removing them from the windowed stats too. New points for a series that isn't in the source are ignored (bar charts have a fixed set of categories). Calls onUpdateData with each series' new points.

    start

    • start(): void

      Subscribes to the generator, handing it the current series, so that a restarted source resumes from the data accumulated so far. Each chunk of data the generator emits is ingested into the series, and then emitted through chartDataUpdatesObservable. When the generator fails or completes, the source stops. A no-op when the source is already running, or has been disposed.

      Returns void
